- Python, JavaScript, TypeScript, React, Node.js

## How I like to work

I prefer tasks with clear acceptance criteria, public reproducible steps, and a focused scope. For bounty work, I usually start by reading the issue, checking existing PRs, estimating risk, then submitting a concise implementation plan before opening a PR.

Best-fit tasks:

- Small bugs
- Test coverage gaps
- Documentation updates
- Build/configuration fixes
- Lightweight scripts and developer tools
- React/TypeScript UI improvements

I generally avoid vague architecture rewrites, production access requirements, private credentials, high-risk protocol/security work, and unpaid long-term maintenance.
